# Experimental Design Practicum

This repository contains my coursework, practical exercises, notes, and experimental design implementations for the **Experimental Design Practicum**.

The practicum covers fundamental concepts of experimental design, single-factor experiments, factorial experiments, randomized designs, Latin square designs, Graeco-Latin square designs, factorial designs, and regression models for experimental designs using R.

## Learning Objectives

Through this practicum, I developed skills in:

* Understanding fundamental concepts and principles of experimental design.
* Designing and analyzing single-factor experiments.
* Applying completely randomized designs.
* Applying randomized complete block designs.
* Applying Latin square and Graeco-Latin square designs.
* Designing and analyzing two-factor factorial experiments.
* Applying factorial designs within completely randomized and randomized complete block designs.
* Understanding and applying 2^k factorial designs.
* Applying regression models to experimental design data.
